# Skills do projeto Atlas

## Para que serve

A pasta `.skills` guarda guias praticos para tarefas repetitivas do projeto Atlas Contabilidade Digital.

Ela ajuda o Codex a lembrar procedimentos importantes sem precisar repetir instrucoes longas em todo prompt.

## Regra principal

O `AGENTS.md` continua sendo a fonte principal de regras do projeto.

Use as skills como apoio pratico, nao como substitutas das instrucoes principais.

## Guias principais e skills

Alguns assuntos tambem possuem arquivos completos na raiz do projeto.

No caso de responsividade, o arquivo principal e `RESPONSIVIDADE.md`.

A skill `.skills/responsividade.md` deve ser usada apenas como checklist rapido. Ela aponta os cuidados mais importantes, mas a referencia completa continua sendo o guia da raiz.

## Quando usar cada skill

- `responsividade.md`: checklist rapido para ajustes de celular, tablet, notebook ou desktop. Para regras completas, leia antes `RESPONSIVIDADE.md`.
- `hero.md`: quando a tarefa envolver a Hero da pagina inicial ou o carrossel visual.
- `paginas-internas.md`: quando a tarefa envolver paginas internas, como servicos, especialidades ou Sobre.
- `especialidades.md`: quando criar ou ajustar paginas de especialidades.
- `servicos.md`: quando criar ou ajustar paginas de servicos contabeis.
- `header-footer.md`: quando mexer no header, menu, dropdown, footer, contato comum ou botao flutuante.
- `animacoes.md`: quando mexer em transicoes, efeitos de entrada, carrosseis ou estados visuais.
- `acessibilidade.md`: quando revisar HTML, botoes, links, imagens, foco e textos alternativos.
- `checklist-final.md`: antes de finalizar qualquer alteracao.

## Como usar

1. Leia primeiro o `AGENTS.md`.
2. Use o Serena para entender os arquivos envolvidos.
3. Abra somente a skill relacionada a tarefa atual.
4. Analise o codigo atual antes de editar.
5. Faca a mudanca por partes, sem reescrever o projeto inteiro.
6. Explique quais arquivos serao modificados e por que.

## O que evitar

- Duplicar regras globais do `AGENTS.md` dentro das skills.
- Usar uma skill sem olhar o codigo atual.
- Criar secoes, layouts ou arquivos fora do escopo pedido.
- Alterar HTML, CSS ou JavaScript que nao esteja relacionado a tarefa.
- Avancar para outra secao sem autorizacao do usuario.
