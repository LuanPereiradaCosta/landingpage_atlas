# Atlas Contabilidade Digital

## Sobre o projeto

Este projeto é uma landing page institucional desenvolvida para a Atlas Contabilidade Digital, com foco em apresentar a empresa, seus serviços e seus diferenciais de forma clara, moderna e profissional.

A proposta visual busca transmitir credibilidade, organização e uma identidade premium, mantendo a navegação simples e objetiva. O projeto também conta com páginas internas, contato via WhatsApp e uma experiência responsiva para diferentes tamanhos de tela.

## Decisões de UI/UX

O visual do projeto foi pensado para transmitir confiança, clareza, modernidade, sofisticação, organização e proximidade no atendimento.

Algumas decisões aplicadas na interface:

- Paleta baseada em tons de azul, com apoio de branco e detalhes discretos.
- Uso de imagens institucionais para reforçar o caráter profissional da marca.
- Overlays em áreas com imagem para melhorar a leitura dos textos.
- Tipografia limpa, moderna e adequada para uma página corporativa.
- Animações suaves para criar uma experiência mais refinada.
- CTAs diretos para facilitar o contato.
- Navegação objetiva entre seções e páginas internas.

## Responsividade

O projeto foi desenvolvido com atenção à responsividade e possui ajustes para diferentes tamanhos de tela, incluindo celular, tablet, notebook, desktop e telas maiores.

Recursos utilizados:

- `clamp()`
- `min()`
- `max-width`
- `grid`
- `flex`
- media queries

## Acessibilidade

O projeto aplica boas práticas de acessibilidade e ainda pode evoluir com testes mais completos.

Boas práticas presentes:

- Uso de HTML semântico.
- Botões com `aria-label` quando necessário.
- Navegação com `aria-expanded`.
- Imagens decorativas com `alt=""`.
- Links com textos compreensíveis.
- Preocupação com contraste entre texto e fundo.
- Suporte a redução de movimento quando aplicável.

## Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/LuanPereiradaCosta/landingpage_atlas.git
```

Entre na pasta:

```bash
cd atlas
```

Depois, abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
